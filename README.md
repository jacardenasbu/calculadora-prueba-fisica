# Calculadora individual de pruebas físicas

Calculadora de la prueba física de la Policía Nacional. Carga el listado de Excel (apellidos y nombres, sexo MA/FE, edad o fecha de nacimiento) y exporta la calificación de cada persona.

No usa OCR. La nota es (puntaje metros + abdominales + pechadas + burpees) × 5 ÷ 1200.
